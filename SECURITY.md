# Security Policy

This repository is a fork of [knaxus/problem-solving-javascript](https://github.com/knaxus/problem-solving-javascript).

- Vulnerabilities in the **original project**: please report them upstream, following the policy at <https://github.com/knaxus/problem-solving-javascript/security>.
- Issues specific to **this fork** (CI, configuration, changes made here): open a private advisory via the **Security** tab of this repository.
